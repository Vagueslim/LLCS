Government Console / API User Journey

Journey ง่ายสุดของช่องทางที่รัฐเป็นผู้เริ่ม: ICP เห็นความต้องการ → เจ้าหน้าที่ค้นฐานข้อมูลหรือ API → ขอสนับสนุน → บันทึกคำตอบ → Resource Card ขึ้น board

Channel G: Government-led

Scenario

happy path แรก
ICP ต้องการกำลังหรือทรัพยากรที่มีเจ้าของชัดเจน เช่น ทหาร ตำรวจ EMS โรงพยาบาล หน่วยงานรัฐ บริษัทคลังสินค้า หรือผู้เชี่ยวชาญที่มีรายชื่อในฐานข้อมูลกลาง
Start Need / Request Task
Middle API Search + Confirm
End Resource Card Ready

Actors

ใครเกี่ยวข้อง
เจ้าหน้าที่รัฐ / ICP Operator เปิด request, ค้นหา, โทร confirm, บันทึกผล
ระบบ LCCS สร้าง task, ดึงข้อมูล, ออก ID, สร้าง Resource Card
หน่วยสนับสนุน ทหาร ตำรวจ EMS เอกชน หรือผู้เชี่ยวชาญที่ถูกร้องขอ
ICP Board เห็นสถานะ confirmed, needs-first, ready หรือ assigned

Main User Journey

เส้นทางหลักจาก request ไปเป็น Resource Card
1

เกิดความต้องการใน ICP

Officer action เลือกประเภทที่ต้องการ เช่น รถสูง, ทีมแพทย์, ตำรวจจราจร, generator
System action สร้าง Request Task พร้อมพื้นที่ เวลา ความเร่งด่วน และเงื่อนไขภารกิจ Request ID
2

ค้นรายชื่อหรือทรัพยากร

Officer action ค้นจากหน่วยงาน พื้นที่ capability asset type หรือรายชื่อผู้เชี่ยวชาญ
API action pull จากฐานกลางหรือ registry ที่เชื่อถือได้ Candidate list
3

เลือก candidate

Officer action เลือกหน่วยหรือคนที่เหมาะกับพื้นที่ เวลา และความเสี่ยง
System action แสดงข้อมูลติดต่อ capability ล่าสุด และประวัติ availability ถ้ามี Shortlist
4

ติดต่อและยืนยัน

Officer action โทร ส่งข้อความราชการ หรือส่ง request ผ่านระบบของหน่วยงาน
Support unit action ตอบรับ ปฏิเสธ ขอรายละเอียด หรือระบุเงื่อนไขก่อนเริ่มงาน Response
5

บันทึกคำตอบ

Officer action บันทึก contact result, ETA, จำนวนคน/อุปกรณ์, needs-first และข้อจำกัด
System action สร้างหรือ update Helper / Unit / Asset / Supply record Resource ID
6

Safety Gate

Decision ติดต่อได้จริงไหม ETA เชื่อถือได้ไหม ต้องการ fuel, route, access pass, operator หรือ staging area ไหม
System action ตั้งสถานะ Ready, Need ICP Support First, Pending หรือ Unavailable Readiness
7

ขึ้น ICP Board

ICP action เห็น Resource Card และเลือก assign mission หรือส่ง support ก่อน
System output last updated, verification status, assignment status และ audit trail Mission-ready card

Console Flow

สิ่งที่เจ้าหน้าที่เห็นเป็นลำดับบนหน้าจอ

Officer Screen Flow

1
Create Requestเลือกประเภททรัพยากร พื้นที่ เวลา ความเร่งด่วน และเหตุผล
2
Search Registry / APIค้นหน่วย คน บริษัท หรือ asset ที่ใกล้และเหมาะกับภารกิจ
3
Contact Candidateกดโทร ส่งข้อความ หรือส่งคำขอไปยังระบบของหน่วยงาน
4
Record Responseตอบรับ ปฏิเสธ รอข้อมูลเพิ่ม หรือพร้อมแต่ต้องการ support ก่อน
5
Push to ICP Boardออก Resource Card และส่งต่อให้ review/assign

Minimum Data Captured

Requestrequest type, area, urgency, mission note, requester
Candidateorganization/person, role, contact, source registry, confidence
Capacitypeople, vehicles, assets, supplies, operating duration
Availabilityready time, ETA, location, transport method
Needs Firstfuel, route, operator, access pass, radio channel, staging area
Auditwho created, who confirmed, timestamp, last updated

Result States

คำตอบหลังรัฐติดต่อ candidate แล้ว
Confirmed Ready ติดต่อได้ ETA ชัด capacity ใช้ได้ และไม่ต้องรอ support เพิ่ม
Confirmed but Needs First พร้อมช่วย แต่ต้องการ fuel, route, operator, access pass หรือ staging area ก่อน
Pending Response โทรไม่ติด รอผู้มีอำนาจตอบ หรือรอข้อมูลจากหน่วยงานต้นสังกัด
Declined / Unavailable ไม่พร้อม ไม่ตรง capability หรือเสี่ยงเกินกว่าจะมอบหมายภารกิจ
Journey Rule Government Console / API ไม่ใช่ฟอร์มรับสมัครทั่วไป แต่เป็นเครื่องมือของรัฐเพื่อเปลี่ยน request ที่เกิดจาก ICP ให้เป็น Resource Card ที่ตรวจสอบได้และพร้อมสั่งการ
