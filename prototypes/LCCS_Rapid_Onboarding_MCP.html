FIELD GUIDE / 01 — RAPID ONBOARDING

แนวคิดและต้นแบบ

จากพร้อมช่วย
สู่พร้อมรับภารกิจ

รับรู้ความช่วยเหลือที่มีอยู่ เห็นเงื่อนไขที่ยังขาด
แล้วให้คนทบทวนก่อนมอบหมายงาน

“ช่วยอะไรได้ และต้องการอะไรก่อน?”

ดูการรับความช่วยเหลือ 4 ช่วง ↓
อ่านบริบทของภาพกรณีสาธิต: ขอ 50 แพ็ก → รับจริง 47 แพ็ก / ตรวจส่วนต่าง 3 แพ็ก+

ภาพนี้แสดงบริบทตั้งแต่เข้าร่วมจนถึงส่งมอบ ส่วนเนื้อหาด้านล่างขยายเฉพาะการรับข้อมูลและทบทวนความพร้อมก่อนมอบหมายงาน

  1. เลือกหรือสร้างองค์กร

    เลือกองค์กรเดิมหรือสร้างใหม่ องค์กรเดิมใช้ต่อได้หลายเหตุการณ์

  2. สร้างทีมสำหรับเหตุการณ์

    แยกทีมตามแต่ละเหตุการณ์ เข้าร่วมผ่าน QR ของทีม โดยส่ง PIN แยกกัน หากไม่มี PIN ให้รอฝ่ายเลขานุการทบทวน ส่วนผู้มีอำนาจอนุมัติทีมยังไม่ได้ยืนยัน

  3. คำขอและพูลร่วม

    กรณีสาธิต A1 ขอรับน้ำดื่ม 50 แพ็ก และ B1 ยืนยันและเปิดพูลร่วม

  4. จัดสรรและขนส่ง

    S1 เสนอขนส่ง · P1 ตรวจยืนยัน · B1 จัดสรรจากพูลร่วม แล้วออกเที่ยวขนส่ง

  5. รับของและกระทบยอด

    A1 รับจริง 47 แพ็ก แล้ว A1 และ B1 ทวนส่วนต่าง 3 แพ็ก จบเที่ยวขนส่งไม่เท่ากับปิดคำขอ

เส้นวนกลับสื่อถึงการส่งต่อข้อมูลและความพร้อม ไม่ได้เปิดคำขอเดิมซ้ำโดยอัตโนมัติ และไม่ได้สร้างองค์กรใหม่ ภาพสร้างด้วย AI เพื่ออธิบายแนวคิดและกรณีสาธิต ไม่ใช่ผลการปฏิบัติงานจริง

หน้านี้อธิบายแนวคิดการทำงาน ยังไม่เชื่อม API หรือระบบรับข้อมูลจริง และไม่ใช่ช่องทางแจ้งเหตุ

ความช่วยเหลือหนึ่งรายการ เดินต่ออย่างไร

คน · ข้อมูล · การตัดสินใจ
