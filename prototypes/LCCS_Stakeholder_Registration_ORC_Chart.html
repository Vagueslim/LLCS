ภาพรวมเส้นทางยืนยันแล้วยังต้องตัดสินใจมีแล้วในโค้ดแค่ไหนข้อเสนอช่องทางเดิม

ยืนยันนโยบาย ≠ ทำแล้วในระบบ ภาพนี้รวมข้อยุติที่ยืนยันแล้วกับขั้นที่ยังออกแบบต่อ ป้ายและเส้นประแสดงจุดเปิดไว้ชัดเจน ลำดับการจัดวางเป็นข้อเสนอเพื่อทบทวน ไม่ได้อนุมัติกฎเพิ่มเติมจากภาพ

เส้นทาง Onboarding ในภาพเดียว

สมาชิกของทีมที่มีอยู่เริ่มที่ 04 โดยเปิด QR/คำเชิญ ไม่ต้องสร้างองค์กรหรือทีมใหม่ • เปิดบนมือถือแสดงขนาดเต็มและเลื่อนภายในกรอบได้ • ขั้นเตรียมสมาชิกกับการขอเข้าร่วมเหตุแยกกัน; เวลาเปิดรับสมาชิกและเงื่อนไขระหว่างสองขั้นยังไม่ล็อกด้วยลำดับภาพนี้

ข้อยุติที่ยืนยันแล้ว

ใช้รหัส OT เดิมเมื่อมีอยู่แล้ว เพื่อไม่สร้างข้อยุติซ้ำ การยืนยันเป็นนโยบายผลิตภัณฑ์ ไม่ได้ยืนยันว่าระบบทำตามครบแล้ว

รหัส / สถานะข้อยุติขอบเขตที่ต้องรักษา
OT-03 · Q04 บางส่วนสมัครบัญชีใหม่ด้วยมือถือ + OTPไม่สรุปเรื่องผู้ให้บริการ OTP การกู้บัญชี การเข้าใช้ครั้งต่อไป หรือการย้ายบัญชีเดิมแทนผู้ใช้
U01–U03ทะเบียนองค์กรใช้ซ้ำข้ามเหตุได้แยกทะเบียนองค์กรจากการเข้าร่วมและขอบเขตสิทธิ์ของแต่ละเหตุ
OT-04a · Q05 บางส่วนผู้ดูแลเหตุรับรองสิทธิ์ผู้ดูแลองค์กรคนแรกรับรองหน้าที่แรก ไม่ได้ถือว่าองค์กร ทีม และคุณสมบัติทั้งหมดผ่านแล้ว
OT-04bคงสถานะผู้ดูแลองค์กรเดิมเมื่อเปลี่ยนเหตุยังตรวจสิทธิ์ปฏิบัติงานในเหตุใหม่; ไม่รับรองตำแหน่งเดิมซ้ำเพียงเพราะเปลี่ยนเหตุ
OT-01 · Q06สร้างทีมใหม่เฉพาะแต่ละเหตุไม่ดึงทีม สมาชิก รถ หรือความพร้อมจากเหตุเก่าเข้ามาอัตโนมัติ
OT-02 · U05–U09PIN ถูก: เข้าเป็นสมาชิกทีมและองค์กรทันที; ไม่กรอก: รอเลขานุการQR มีเฉพาะลิงก์ทีม ส่ง PIN 4 หลักแยก; ไม่เพิ่มอนุมัติสังกัดซ้ำในทาง PIN
U09เปลี่ยน PIN หรือปิดรับ ไม่ทำให้สมาชิกเดิมหลุดทีมคำขอที่ยังค้างและช่องทางเชิญอื่นยังต้องเลือกกติกา
ขอบเขตอำนาจสมาชิกหรือ badge ต้นสังกัดไม่ให้สิทธิ์ DAO และไม่ทำให้พร้อมปฏิบัติการการลงทะเบียน การรับเข้าเหตุ การมอบสิทธิ์ ความพร้อม และการรับภารกิจแยกกัน

เรื่องที่ยังต้องตัดสินใจ

Q04 ยืนยันหลักมือถือ+OTP แต่รายละเอียดยังเปิด; Q05 ยืนยันผู้รับรองคนแรกและความต่อเนื่องบางส่วน; Q06 ยืนยันทีมใหม่เฉพาะเหตุแล้ว รหัส ORC-P01–P05 ใช้จัดกลุ่มคำถามบนหน้านี้ ไม่แทนรหัสเดิมในสเปก

รหัสคำถามขอบเขต / ทางเลือกที่ยังไม่เลือก
OT-04c · Q05 ส่วนที่ยังเปิดใครอนุญาตทีมเข้าร่วมเหตุก ฝ่ายเหตุอนุมัติรายทีม / ข ฝ่ายเหตุอนุญาตองค์กรและขอบเขตก่อน แล้วผู้ดูแลองค์กรอนุมัติทีมของตนภายในขอบเขตนั้น — ยังไม่เลือก
ORC-P01ใครสร้างเหตุ และใครแต่งตั้งผู้ดูแลเหตุAdmin สร้างเหตุและแต่งตั้งเป็นข้อเสนอ ยังไม่ได้ยืนยันเป็นกติกาหรือความสามารถปัจจุบัน
ORC-P02 · Q04 รายละเอียดระบบบัญชีและ OTPผู้ให้บริการ การกู้บัญชี การเข้าใช้ครั้งต่อไป เลขซ้ำ/บัญชีเดิม/Person กลาง และวิธีสำรองเมื่อ OTP ใช้ไม่ได้
ORC-P03ข้อยกเว้นสมาชิกและผู้แทนองค์กรคำขอค้างเมื่อปิดรับ คำเชิญที่ไม่ผ่าน QR ผู้แทนคนอื่น หลักฐาน/ชื่อซ้ำ/รวมองค์กร และการกู้สิทธิ์เมื่อไม่มีผู้ดูแล
ORC-P04สิทธิ์และความพร้อมก่อนทำงานผู้ให้สิทธิ์ราย action อายุ/การสิ้นสุดสิทธิ์ของบทบาทนี้ ผู้ตรวจความพร้อม และผู้รับช่วงงานค้าง ต้องออกแบบเฉพาะเรื่อง; ผู้ช่วยยืนยันได้เฉพาะ action ที่ DAO มอบ ไม่ใช้การสมัครแทน
ORC-P05ช่องทางลงทะเบียนของแต่ละกลุ่ม5 ช่องทาง / 12 กลุ่ม รวม Government API, bulk import, app/link และโทรศัพท์เป็นข้อยกเว้น ยังเป็นข้อเสนอเดิม ไม่ใช่ข้อยุติการเชื่อมระบบ

ข้อยุติกับสิ่งที่มีในโค้ด

สแนปช็อตจากการตรวจโค้ด 13 พฤศจิกายน 2026 แยกจากวันที่ปรับเอกสาร และไม่ใช่สถานะข้อมูลผู้ใช้สด

มีในระบบท้องถิ่น / เดโม

ฐานบัญชี องค์กร ทีม

มีบัญชีและสิทธิ์พื้นฐาน การสร้างองค์กร คำเชิญ สมาชิกทีม และเดโมน้ำหนึ่งเที่ยวที่แยกคำขอ ข้อเสนอทีม จัดสรร และผลรับจริง

ยังไม่ครบตามเป้าหมาย

รับเข้าเหตุและทรัพยากร

มือถือ+OTP การรับรองผู้ดูแลองค์กรคนแรก การอนุญาตทีมเข้าเหตุ QR/PIN ตามข้อยุติ และทะเบียนทรัพยากรยังไม่ครบ; Audit กลางยังไม่ครบ

ยังเป็นข้อเสนอช่องทาง

Gov API / Bulk / App

หน้านี้ไม่มี API รับข้อมูลจริง ไม่มีการส่ง OTP และไม่มีการอนุมัติจากหน่วยงานจริง การวางช่องทางไม่ได้ยืนยันว่าต่อระบบภายนอกแล้ว
