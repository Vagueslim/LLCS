LCCS Stakeholder Registration ORC Chart

ตั้งต้นจากผู้เกี่ยวข้องก่อน แล้วค่อยกำหนดช่องทางลงทะเบียนที่เหมาะสม: ใครควรเข้าระบบผ่านรัฐ ใครผ่านหน่วยงานต้นสังกัด ใคร self-register และโทรศัพท์ควรเป็นทางฉุกเฉินเท่านั้น

Channels 5 ช่องทางหลัก
หลักตั้งต้น กลุ่มที่มี chain of command หรือมีองค์กรต้นสังกัด ไม่ควรลงทะเบียนรายคนผ่านโทรศัพท์เป็นหลัก ให้ใช้ Government Console/API หรือ Unit Coordinator Bulk ส่วนประชาชนและผู้เชี่ยวชาญอิสระใช้ Official Link, App/QR และยืนยันตัวตนด้วยเบอร์โทรหรือ application
LCCS Rapid Onboarding เปลี่ยนผู้เกี่ยวข้องให้เป็น Resource / Unit / Asset / Supply Card ที่ ICP ใช้สั่งงานได้
G

Government Console / API

เจ้าหน้าที่รัฐหรือ ICP เปิด task, ดึงฐานข้อมูลกลาง, โทร confirm และสร้าง record แบบมีอำนาจสั่งการ

รัฐเป็นผู้เริ่ม
O

Organization / Unit Bulk

ผู้ประสานงานหน่วย ท้องถิ่น บริษัท มูลนิธิ หรือคลังสินค้า upload รายชื่อ กำลังคน asset และ capability

delegate กรอกแทน
L

Official Link / Chat Form

ประกาศทางการหรือ chat bot เปิด form ให้ลงทะเบียนและเก็บ source trace ของประกาศ/พื้นที่

self-entry เร็ว
A

App / QR Self Registration

download app หรือสแกน QR เพื่อยืนยันตัวตนด้วยเบอร์โทร อุปกรณ์ หรือ account แล้วสร้าง profile

identity ดีกว่า
P

Phone Intake Exception

ใช้เมื่อจำเป็นเท่านั้น เก็บข้อมูลขั้นต่ำ สร้าง Temporary ID แล้วส่ง link หรือส่งต่อให้หน่วยงานย่อยรวบรวม

ไม่ใช่ช่องทางหลัก

Stakeholder → Registration Route

Primary = ช่องทางหลัก, Secondary = ใช้เสริม, Exception = เฉพาะจำเป็น

ทหาร 01

เป็นหน่วยมี chain of command ชัด ควรเข้าด้วยคำสั่ง/การประสานทางการ ไม่ใช่ self-register รายคน

PrimaryGovernment Console / API
SecondaryUnit Bulk จาก liaison
Exceptionโทรเฉพาะ contact point

ตำรวจ 02

เหมือนทหาร ข้อมูลควรมาจากศูนย์ประสานหรือผู้แทนหน่วย เพื่อรักษาความถูกต้องของกำลังและพื้นที่รับผิดชอบ

PrimaryGovernment Console / API
SecondaryUnit Bulk / roster
Exceptionโทร confirm เฉพาะหัวหน้าชุด

หน่วยกู้ภัย / ผจญเพลิง 03

มีทั้งองค์กรและทีมอิสระบางส่วน เหมาะกับ unit bulk จากมูลนิธิ/สถานี และ link สำหรับทีมที่เข้ามาเอง

PrimaryOrganization / Unit Bulk
SecondaryGovernment Console Official Link
Exceptionโทรเมื่อเข้าพื้นที่แล้ว

EMS / แพทย์ฉุกเฉิน / Mobile Clinic 04

ต้องคุมคุณสมบัติและความปลอดภัยสูง ควรเข้าผ่านหน่วยงานสุขภาพ โรงพยาบาล หรือคำขอจากรัฐ

PrimaryGovernment / Health Console
SecondaryHospital / clinic bulk
OpenApp สำหรับบุคลากรอิสระที่ยืนยันตัวตนได้

เจ้าหน้าที่ท้องถิ่น 05

ควรเป็น delegate สำคัญ เพราะกระจายภาระจาก ICP ไปยัง อปท. หมู่บ้าน ชุมชน และศูนย์ย่อย

PrimaryLocal Delegate / Bulk
SecondaryGovernment Console / API
UseOfficial Link สำหรับทีมชุมชน

อาสาสมัครประชาชน 06

กลุ่มนี้ควร self-register เป็นหลัก และถ้ามาเป็นกลุ่มให้ local delegate รวบรวมแทน

PrimaryApp / QR Self Registration
SecondaryOfficial Link / Chat Form
GroupLocal Delegate Bulk

วิศวกร / ช่างโครงสร้าง / ไฟฟ้า / ประปา 07

เป็นผู้เชี่ยวชาญที่ต้องจับคู่ภารกิจให้ถูก ควรมีทั้ง self-entry และการรวบรวมผ่านสมาคม/บริษัท

PrimaryApp / QR + skill verification
SecondaryProfessional / company bulk
Requestรัฐติดต่อ expert โดยตรง

นักจิตวิทยา 08

ต้องแยก credential และพื้นที่ให้บริการ ควรผ่านองค์กรวิชาชีพ หน่วยสุขภาพ หรือ self-register แบบยืนยันตัวตน

PrimaryProfessional / health org bulk
SecondaryApp verified profile
RequestGovernment direct contact

ทีม ICT & สื่อสาร 09

อาจเป็นทีมบริษัท วิทยุสมัครเล่น ผู้ดูแล network หรือทีมเฉพาะกิจ ต้องจับ capability กับพื้นที่และอุปกรณ์

PrimaryTeam / company bulk
SecondaryApp / QR สำหรับรายบุคคล
Requestรัฐขอสนับสนุนเฉพาะทาง

สื่อมวลชน / ประชาสัมพันธ์ 10

ควรแยกจาก resource field operation เป็น media accreditation และ public information support

PrimaryOfficial Media Link / Form
Secondaryสำนักข่าว / ทีมประชาสัมพันธ์ bulk
ControlPIO / Government approval

ผู้ประเมินพื้นที่ / สำรวจความเสียหาย 11

ต้องผูกกับพื้นที่สำรวจและมาตรฐานรายงาน ควรใช้ app/form ที่เก็บ location และข้อมูลเชิงโครงสร้างได้

PrimaryApp / QR + geo form
Secondaryหน่วยสำรวจ / องค์กร bulk
RequestICP assign survey task

ภาคเอกชน / คลังสินค้า / ซัพพลายเออร์ 12

เหมาะกับ organization account, API หรือ bulk list เพราะมีสินค้า asset ปริมาณ รอบส่ง และ logistics condition

PrimaryCompany / warehouse bulk
SecondaryGovernment request / API
OpenOfficial supply form
